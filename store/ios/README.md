## Asset Guidelines

### App Icons
- Use PNG format with no transparency
- Ensure icons are crisp and clear at all sizes
- Follow Apple's Human Interface Guidelines
- Use consistent branding across all sizes

### Screenshots
- Show actual app functionality
- Use real data, not placeholder text
- Ensure screenshots are high quality
- Show key features and user flows
- Use consistent styling and branding

### App Preview Videos
- Show app in action
- Highlight key features
- Keep videos under 30 seconds
- Use high quality video
- Include captions for accessibility

## Submission Checklist

- [ ] All app icons are present and correct sizes
- [ ] All screenshots are present and correct sizes
- [ ] App preview videos are under 30 seconds
- [ ] All assets follow Apple's guidelines
- [ ] Assets are optimized for file size
- [ ] Assets are tested on actual devices
- [ ] Assets are reviewed for quality

## Tools for Asset Creation

### App Icons
- Use Figma or Sketch for design
- Use ImageOptim for compression
- Use App Icon Generator for multiple sizes

### Screenshots
- Use iOS Simulator for screenshots
- Use Figma for mockups
- Use ImageOptim for compression

### App Preview Videos
- Use iOS Simulator for recording
- Use Final Cut Pro or Adobe Premiere for editing
- Use HandBrake for compression

## Notes

- All assets should be optimized for file size
- Test assets on actual devices before submission
- Follow Apple's App Store Review Guidelines
- Ensure assets are accessible and inclusive
- Keep assets updated with app changes
