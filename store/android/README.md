## Asset Guidelines

### App Icons
- Use PNG format with no transparency
- Ensure icons are crisp and clear at all sizes
- Follow Material Design guidelines
- Use consistent branding across all sizes
- Support adaptive icons for Android 8.0+

### Adaptive Icons
- Foreground layer should be 108x108dp
- Background layer should be 108x108dp
- Ensure icons work with various mask shapes
- Test on different Android versions
- Use safe zone for important elements

### Screenshots
- Show actual app functionality
- Use real data, not placeholder text
- Ensure screenshots are high quality
- Show key features and user flows
- Use consistent styling and branding
- Follow Material Design principles

### Feature Graphic
- Use PNG format with no transparency
- Include app name and key features
- Use high contrast for readability
- Follow Google Play design guidelines
- Optimize for file size

### App Preview Videos
- Show app in action
- Highlight key features
- Keep videos under 30 seconds
- Use high quality video
- Include captions for accessibility
- Follow Google Play video guidelines
